# 尺度 · 建工裁判规则 100 讲 · 规则卡

把建设工程施工合同纠纷里已经生效的裁判规则，压缩成一张张可检索、可核验的卡片。

每条卡片只回答五件事：**争点是什么、规则怎么判、判例在哪里、什么条件下结论翻转、可以立即去做什么**。

## 这是什么

《尺度》是一个持续写作的建工裁判规则专题：从人民法院案例库、最高人民法院公报案例与优案评析中，每一讲精读一个真实裁判，写成一篇可直接使用的文章。这套规则卡是它的检索层——把每讲压到一屏以内，保留判断所需的最小信息集，去掉论证过程与修辞。

## 怎么用

打开 [index.html](index.html)（GitHub Pages 上线后可直接访问），支持两种检索：

1. **全文搜索**：标题、争点、规则、案号、法院、当事人，输入即筛。
2. **五维标签**：同一组内多选取并集，跨组取交集。
   - **卷次**：卷一（主体资格）、卷二（工期与质量）分开看
   - **身份**：你是内部承包人、挂靠人、实际施工人、分公司，还是出借资质的企业
   - **可诉对象**：这钱能向发包人、总包、前手、分公司还是签字个人要
   - **胜负手**：决定输赢的那一件事（劳动关系、资金流向、授权与印章、发包人知情……）
   - **新规**：是否受《建工解释二》影响，落在第几条

典型问法：「我是挂靠人，能不能直接告发包人」→ 身份选「挂靠」＋对象选「发包人」。

## 数据与核验

- 每张卡的**判例坐标**（案件名称、法院、案号）都取自公开裁判文书与公开出版的案例编选，可在原卷宗中反查。
- 卡片正文区分三层文本：**判决理由**（承办法官写的）、**裁判要旨与案例评析**（案例编写人写的，不是判决正文）、**当事人主张**（单方陈述，不是法院认定）。卡片只写自撰要旨，不转录评析原文。
- 已发布的 40 张卡，主案号与反向案例案号均通过脚本逐条回查对应讲稿底本，零未命中。
- 规则会变。卡片标注了《建工解释二》（法释〔2026〕12 号）施行后的变化，但**不替代对现行法和最新司法解释的核对**。

## 这不是什么

- 不是判决书全文，也不是案例汇编；引用判决原文请回到原卷宗。
- 不是法律意见。个案的事实、证据、时效、管辖都可能改变结论，具体案件请咨询执业律师。
- 不是对所有法院的预测。同类争点在不同法院、不同时期仍有分歧，卡片里的「翻转条件」就是为这件事留的位置。
